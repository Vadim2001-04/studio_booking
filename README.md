# ФотоСлот — система бронирования фотостудий (MVP)

Веб-приложение на Python/Flask: фотограф или клиент находит фотостудию (зал), выбирает дату и свободный часовой слот и бронирует его. Владелец студии (администратор) управляет залами и видит все брони.

## Возможности MVP

**Пользователь**
- каталог залов с фильтром по типу (интерьерная, циклорама, предметная съёмка, видео и подкасты);
- карточка зала: описание, цена, календарь на 14 дней вперёд, сетка часовых слотов (свободно / занято / прошло);
- регистрация, вход, выход;
- бронирование слота в один клик (с подтверждением);
- «Мои брони»: история, статусы, отмена будущей брони.

**Администратор**
- список залов, добавление и редактирование (название, тип, адрес, описание, цена за час, часы работы);
- скрытие зала из каталога без удаления;
- все брони с фильтрами по залу и статусу, сумма активных броней;
- отмена любой брони.

**Бизнес-правила**
- нельзя забронировать занятый слот (проверка уникальным индексом в БД — защищает и от одновременных запросов);
- нельзя бронировать время в прошлом, вне часов работы студии и дальше чем на 14 дней;
- пользователь отменяет только свои и только ещё не начавшиеся брони;
- цена фиксируется в брони на момент бронирования (изменение цены зала не меняет старые брони).

## Запуск

Нужен Python 3.10+.

```bash
cd studio_booking
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
python app.py
```

Открыть в браузере: http://127.0.0.1:5000

При первом запуске создаётся файл `booking.db` с четырьмя тестовыми залами и администратором:

| Роль | Email | Пароль |
|---|---|---|
| Администратор | admin@example.com | admin123 |

Обычного пользователя создайте через «Регистрация». Чтобы начать с чистыми данными — остановите приложение и удалите `booking.db`.

```

│   └── style.css       # оформление

    ├── base.html       # общий каркас: шапка, меню, уведомления
    ├── index.html      # каталог залов
    ├── studio.html     # зал: выбор даты и слота
    ├── my_bookings.html
    ├── login.html, register.html, error.html
    └── admin/          # админ-панель: залы, форма зала, все брони
```

## Модель данных

- **users** — пользователи: имя, email (уникальный), хеш пароля, признак администратора.
- **studios** — залы фотостудий: название, тип, адрес, описание, цена за час, часы работы, активна ли.
- **bookings** — брони: пользователь, зал, дата, час начала слота, цена, статус (`active` / `cancelled`).

Слот = один час: бронь с `hour = 18` означает 18:00–19:00.

## Маршруты

| Метод | URL | Что делает |
|---|---|---|
| GET | `/` | каталог, `?category=` — фильтр |
| GET | `/studio/<id>?date=YYYY-MM-DD` | зал и слоты на дату |
| POST | `/studio/<id>/book` | забронировать слот |
| GET | `/my-bookings` | мои брони |
| POST | `/booking/<id>/cancel` | отменить бронь |
| GET/POST | `/register`, `/login` | регистрация, вход |
| GET | `/logout` | выход |
| GET | `/admin/studios` | админка: залы |
| GET/POST | `/admin/studios/new`, `/admin/studios/<id>/edit` | добавить / изменить зал |
| GET | `/admin/bookings?studio_id=&status=` | админка: все брони |
